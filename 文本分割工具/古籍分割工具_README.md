# 古登堡繁体中文古籍 · 分割工具

把古登堡计划（Project Gutenberg）下载的繁体中文 txt，按「本纪/表/书/世家/列传」等**标题层级**切成逐篇 txt + 按类分组 txt。

## 文件说明

| 文件 | 作用 |
|------|------|
| `split_gutenberg.py` | 通用分割脚本（核心，只需这一个） |
| `test_regex.py` | 正则单元测试，验证三本书标题识别 |
| `verify_split.py` | 分割后内容校验（残留英文、首尾、重名） |

## 使用步骤

**1. 放置文件**：把脚本与古登堡下载的 txt **放在同一个文件夹**即可。文件名随意（简体/繁体均可），脚本自动识别：

```
你的文件夹/
├── split_gutenberg.py
├── 史記.txt        (或 史记.txt / 史記_繁 古登堡.txt)
├── 漢書.txt        (或 汉书.txt)
└── 三國志.txt      (或 三国志.txt)
```

> 只有放进去的书才会被处理；没放的书自动跳过，不会报错。

**2. 运行**（Mac / Linux 终端）：

```bash
cd 你的文件夹
python3 split_gutenberg.py
```

**3. 校验**：

```bash
python3 verify_split.py
```

## 三本书的配置（已内置，无需修改）

| 书 | 标题格式示例 | 类别 | 预期篇数 |
|----|------------|------|---------|
| 《史記》 | `史記 五帝本紀` | 本紀 / 表 / 書 / 世家 / 列傳 | 130 篇（实际 129 标题 + 重名拆分） |
| 《漢書》 | `漢書 高帝紀第一` | 紀 / 表 / 志 / 傳 | 约 100 篇 |
| 《三國志》 | `三國志 魏書 武帝紀第一` | 魏書 / 蜀書 / 吳書 | 约 65 卷 |

> 《漢書》《三國志》实际篇数以古登堡具体版本为准。

## 核心正则

脚本已自动兼容：**全角空格（　）/ 半角空格 / Tab**、**标题末尾带序号**（如「第一」「第十」）、**类别词在行中**（如《三国志》的「魏書」后面跟「武帝紀第一」）。

```
史記：  ^史記[ \u3000\t]+.*(?:本紀|表|書|世家|列傳)$
漢書：  ^漢書[ \u3000\t]+.*(?:紀|表|志|傳)
三國志：^三國志[ \u3000\t]+.*(?:魏書|蜀書|吳書)
```

## 输出结构

每本书生成独立的 `<书名>_分割/` 目录：

```
史記_分割/
├── by_piece/    # 逐篇：史記 五帝本紀.txt、史記 貨殖列傳.txt ...
└── by_category/ # 按类分组：01_benji.txt、05_liezhuan.txt ...
```

- 自动剔除古登堡英文许可页眉页脚、`***` 标记行、纯英文行（校验：残留英文 = 0）
- 重名篇目自动编号：`高祖本紀.txt` / `高祖本紀_2.txt`
- 编码：UTF-8 with BOM（Windows/Mac 记事本均正常）

## 已验证

- ✅ 《史記》真实源文件：129 标题 → 126 文件（3 对重名拆分），纯英文残留 **0**，总字符 645,397
- ✅ 《漢書》《三國志》正则单元测试：全部通过（含全角空格、序号后缀等边界）

## 若需支持新书

在 `split_gutenberg.py` 的 `BOOKS` 字典中新增一项（类别词 + 分组名 + 标题正则）即可，前端架构无需改动。
