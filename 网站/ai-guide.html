📖 AI 新手指南

本站 AI 能力分两层：全局 AI 助手（全站通用）＋ 章节 AI 学习模式（沉浸式阅读）

一、全局 AI 助手（全站通用）

  • 在哪打开？ 任意页面左下角的 🤖 圆形按钮。
  • 能做什么？ 三种模式：💬 通用问答（古籍常识、字词解释）、🈷 翻译（繁/文言 → 白话）、📚 书籍推荐（按兴趣荐书）。
  • 章节上下文： 在章节阅读页打开助手时，会自动带上「当前书名 · 作者 · 章节」作为上下文，提问会优先结合该章节。
  • 需要配置： 首次使用请先到 ⚙ AI 设置 填入你的 DeepSeek API Key（保存在本地浏览器）。

二、章节 AI 学习模式（阅读页内，独立使用）

  • 入口 1： 章节阅读页右下角「🤖 深度学习」按钮 —— 把当前整篇送入 AI 阅读器，保留阅读位置。
  • 入口 2： 在章节正文选中一段文字，会弹出「AI 解读选中文字」，只解读选中的片段。
  • AI 阅读器功能： 逐句翻译、疑难字词精讲、深度学习（段落解读）、相关文史背景、智能测验（选择题 / 判断 / 填空 / 问答）、组卷练习与自动阅卷。
  • 切换模型： 阅读器左侧设置栏可选「站长提供的 DeepSeek V4-Flash（免费代理，限速限字数）」或「使用自己的 API Key」。

三、获取 DeepSeek API Key

  1. 打开 platform.deepseek.com 注册并登录。
  2. 左侧「API Keys」→「创建 API Key」，复制 sk-… 格式的密钥。
  3. 回到本站 ⚙ AI 设置 粘贴保存，点「🧪 测试连接」验证。

四、常见问题

  • Key 安全吗？ 只存本地浏览器，直连 DeepSeek，不经本站服务器。
  • 为什么有时提示限流？ 「站长提供」的代理有 60 秒 10 次的限制；改用自己的 Key 可解除。
  • 输入过长？ 单次请求上限约 3000 token（约 5000 字），长文请分段落提问。
  • 想换别的模型？ 到 AI 阅读器设置侧栏切换服务商（OpenAI / Qwen / Kimi / GLM / 豆包 / 自定义端点）。
