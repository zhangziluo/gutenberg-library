⚙ AI 设置

全局 AI 助手与章节 AI 学习模式共用同一把 Key

DeepSeek API Key

1. 到 platform.deepseek.com 注册并创建 API Key（格式 sk-…）。
2. 粘贴到下面并保存，即可在全站使用 AI 助手（问答 / 翻译 / 书籍推荐）与章节 AI 学习模式。

隐私与安全

  • Key 只保存在你本机浏览器（localStorage），不上传本站服务器，也不写入任何云端存储。
  • 全局 AI 助手使用你的 Key 直连 DeepSeek 官方接口；AI 阅读器也可选「站长提供」的免费代理（无需 Key，但限速、限字数）。
  • 请勿在公共电脑上保存 Key；如需换用其他服务商（OpenAI、Qwen、Kimi、GLM、豆包、自定义端点），请到 AI 阅读器的设置侧栏切换。
  • 所有 AI 请求都会消耗你自己的 DeepSeek 额度，请留意用量。
