# 史记 AI 阅读器（古文自学工具）

一个面向高密度文本（首选文言文）的自学阅读器原型：**AI 不等待你提问，而是懂你读到哪了**——鼠标移到哪句自动翻译，空闲时自动补全剩余，一键生成学习卡片（选择/填空/问答）。支持导入本地 TXT/EPUB，也可直接调用一堆古书在线文库（无需本地文件）。

## 文件说明

| 文件 | 作用 |
|---|---|
| `shiji_reader.html` | 主阅读器。粘贴/导入古文，AI 逐句辅助 + 学习卡片 |
| `library.html` | 一堆古书在线文库（**通用**，不只史记）。搜索优先 + 经史子集分类 + 常用典籍快速入口 + 最近阅读，聚合 CTEXT 与古诗文网 |
| `guoxue_catalog.js` | 通用古籍目录数据（经/史/子/集 + 史记全 130 篇），供文库按分类浏览典籍与篇目 |
| `shiji_catalog.js` | 《史记》全 130 篇目录数据（本纪/表/书/世家/列传分类，含 CTEXT slug），被 `guoxue_catalog.js` 复用 |
| `epub_split.html` | EPUB 分割小工具。大文件按章节/字数/关键词分组拆成小份再导入 |

## 快速开始

### 1. 直接用在线文库（无本地文件）
1. 双击打开 `shiji_reader.html`，点击顶部 **"📚 在线文库"** 按钮（会新开 `library.html`）。
2. 在文库中**搜索任意篇目/作者/关键词**（如"逍遥游""货殖""李白"），或从"常用典籍/经史子集"挑选（内置：史记、论语、孟子、老子、庄子、楚辞、汉书等）。选篇后点"加载"。
3. 点"阅读/加载"，原文写入会话存储。**回到阅读器**，原文自动填入阅读区。
4. 填入 DeepSeek API Key（默认已选 DeepSeek），开始阅读——鼠标移到句子即自动翻译。

### 2. 导入本地文件
- 主阅读器支持 **导入 TXT**（逐句辅助全功能）和 **导入 EPUB**（epub.js 渲染 + 章节辅助）。
- 大 EPUB（如整本《史记》）请先用 `epub_split.html` 拆分：选文件 → 选策略（按章节/字数/关键词分组）→ 导出 ZIP → 回到阅读器用"导入 TXT"逐个导入小 txt。

### 3. 获取 API Key
- DeepSeek（默认推荐，已充值可用）：登录 platform.deepseek.com → API Keys → 创建 Key（`sk-` 开头）。
- 腾讯混元：cloud.tencent.com → 混元/TokenHub 控制台 → API Key 管理。

## AI 辅助交互说明
- **逐句翻译（不出题）**：鼠标移到某句 / 滚动到某句，自动请求单句翻译+采分点，内联显示在该句下方并同步到右侧辅助面板；已译句子缓存，不重复请求。
- **空闲自动补全**：连续空闲达设定秒数（默认 15 秒），自动补全剩余未译句（仍只翻译不出题）。
- **生成学习卡片**：点"📝 生成学习卡片"，得到全文翻译 + 3-5 道检测题（含答案，可展开解析），此后自动逐句模式停止。

## 注意事项
- **API Key 安全**：当前为浏览器直连，Key 出现在前端请求中，仅适合个人试用。给他人使用前务必加后端代理（Vercel Serverless / Cloudflare Worker 等），Key 仅存服务端。
- **第三方跨域**：CTEXT 与古诗文网均非为本工具提供官方 API，受匿名调用限流与跨域策略影响，个别浏览器或篇目可能加载失败，此时可改用"关键词检索（古诗文网）"或本地导入 txt。
- **EPUB 本地打开**：epub.js 在 `file://` 下加载本地文件通常无碍，但若遇跨域问题，建议用简单 HTTP 服务（如 `python -m http.server`）打开，或直接使用 TXT 模式。
