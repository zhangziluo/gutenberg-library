
# 一堆古书

> 没什么正经的，就是一堆古书。

一个中英文在线阅读站，中文按经史子集归类，英文接古登堡计划，从初级到高级都有。（待上线）带生僻字即时释义、五部分类、AI 助手和每日一句一卦。

🌐 在线体验：[myfami.cn](https://myfami.cn)（部署中，暂可用 [myfami.pages.dev](https://myfami.pages.dev)）

---

## 这是什么

古登堡计划的中文公版书不算多，但胜在干净。这个站点把其中已整理的中文古籍和近现代文学做成了**带辅助阅读功能的在线版本**——不是简单的 TXT 堆砌，而是试图让古文阅读变得"零障碍"。

## 核心功能

- 📚 **五部分类** —— 经、史、子、集、丛。不是"小说/非小说"这种偷懒分法，是给每本书找个文化户口本。
- 🔴 **红字释义** —— 正文中的生僻字带红色下划线，点击即看拼音和释义。不用切出去查字典，阅读流不断。
- 📜 **今日一句** —— 每天一句古文，点一下换一条。
- ☯️ **今日一卦** —— 每天一卦，配易经原文。当签抽着玩。
- 🤖 **AI 助手** —— 接入 DeepSeek，支持通用问答、翻译、书籍推荐，回答可保存为笔记。

## 能干嘛

**已经有了：**
- 📖 读公版书——中文古书 + 英文原版，目前入库 60+ 本，还有 60 本英文书号待入库

## 为什么开源

一个人搬书太慢，一个人标释义太累。这个站点的代码和数据结构完全开放，任何人都可以：

- 提交新书（按模板提供文本和元数据）
- 补充红字释义数据（字 → 拼音 + 释义）
- 提 bug、提功能建议、提交 PR

站长是个汉语言文学系毕业生，代码写得一般，纯靠AI编程把这个网站做了出来。欢迎各路高手来帮忙。

## 如何贡献

### 提书
1. Fork 本仓库
2. 将书籍文本按 `books/[分类]/[书名]/index.md` 格式放入
3. 填写 `metadata.json`（书名、作者、朝代、分类、简介）
4. 提交 PR
